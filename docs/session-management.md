# 세션 관리

데스크톱 터미널 캔버스의 기존 `Context` 탭을 `세션 관리`로 바꾸었다. 캔버스 사이드바의 각 세션에 있는 `관리` 버튼도 같은 패널을 연다. 새 모바일 진입점은 추가하지 않았다.

## 화면과 작업 흐름

패널 상단에는 세션 이름, 담당 감독, 현재 상태를 표시한다. `목표·설정`에서 설정을 편집하고 `변경 저장`을 누른다. `진행·근거`에서는 최근 보고 시각, 수행한 일, 막힌 이유, 다음 작업, 남은 완료 조건과 검증 근거를 확인한다. 보고가 없으면 빈 상태를 그대로 안내한다.

`체크리스트`에서는 해당 세션의 할 일을 추가하고 완료 체크·해제·삭제한다. 미완료를 먼저 보여 주고 완료 기록은 접어 둔다. 체크 개수는 전체 목표 달성 판정과 별개다.

각 세션은 완료 기록을 포함해 최대 50개를 유지한다. 51번째 항목을 추가하면 가장 오래 전에 완료한 항목부터 자동 삭제한다. 미완료가 50개이면 추가를 거절하고 기존 입력을 유지한다. 다른 세션의 항목과 미완료 작업은 자동 삭제하지 않는다.

작업자 자동 지시는 자기 체크리스트를 먼저 읽고 필요한 항목을 등록하며, 검증한 작업만 완료 체크하도록 안내한다. 기존 작업 API를 공유한다: `POST /api/board/tasks {termId, supervisorId, text}`, `PATCH /api/board/tasks/T-ID {done:true}`. 저장소의 CLI도 `task add "할 일" --session <고정 termId>`를 지원한다.

| 항목 | 의미 |
| --- | --- |
| 현재 목표 (`objective`) | 이 세션이 맡을 작업이다. 비어 있으면 자동 지시에서 완료 조건을 대신 사용한다. |
| 완료 조건 (`goal`) | 완료로 인정하기 위해 확인할 결과이다. 필수이며, 현재 목표와 각각 최대 2000자까지 저장한다. |
| 작업 우선순위 (`priority`) | 1 높음, 2 보통, 3 낮음 순서로 다음 자동 지시와 감독 배정에 반영한다. 기본값은 2이다. |
| 자동 지시 일시정지 (`paused`) | 새 자동 지시를 멈춘다. 이미 실행 중인 명령을 종료하지 않는다. |

자동 지시 상태는 감독별 자동 진행 모드, 운영 기한, 개별 일시정지를 함께 계산한다. 독립 진행은 전체 현황의 작업자 자동 진행 설정에서 켜며, 감독이 중지되어도 작업자는 저장된 목표를 이어간다. 승인과 사용자 대화 보호는 유지한다.

설정은 감독보드와 같은 작업자 배정에 저장한다. 미배정 세션은 담당 감독을 선택하고 완료 조건을 저장해 연결한다. 이미 배정된 세션의 감독 선택은 해당 세션이 속한 배정을 조회·편집한다.

감독 자신의 세션에서는 작업자 편집 대신 감독 목표와 `감독보드에서 관리` 버튼을 보여 준다. 감독보드의 기존 역할과 관리 기능은 유지하며, 이 변경은 감독보드를 감독 전용 역할 화면으로 이관하는 작업이 아니다.

## 저장과 충돌 처리

작성 중인 값과 선택한 탭은 같은 페이지에서 패널을 다시 열어도 유지된다. 보드 갱신은 저장하지 않은 입력을 덮어쓰지 않는다. 페이지를 떠날 때 저장하지 않은 변경이 있으면 브라우저 확인을 요청한다. 새로고침 후 복구를 위한 영구 임시 저장은 제공하지 않는다.

다른 화면에서 설정이 바뀌면 기존 입력을 보존하고 저장을 막는다. 서버도 `PATCH /api/board/worker-settings`의 기존 설정 스냅샷을 비교하여 오래된 수정 요청을 409로 거절한다. `최신 설정`은 작성 중인 변경을 버릴지 확인한 뒤 서버 값을 불러온다. 저장 실패 시 입력과 오류 안내를 유지한다.

현재 목표나 완료 조건을 변경하면 이전 진행 상태와 보고 토큰을 무효화한다. 이전 목표의 토큰으로 보낸 완료 보고는 새 목표에 반영하지 않는다. 작업자의 완료 보고는 감독 검증 전까지 `완료 검증 대기`로 표시한다.

감독의 전체 목표만 변경하고 작업자 자신의 목표·완료 조건이 같으면 작업자 진도와 보고 토큰은 유지한다. 작업자가 직접 보고한 다음 작업과 결과물 근거는 감독 응답 없이 표시하며, 검증 완료 근거와 구분한다. `진행 보고 있음`은 저장된 보고 상태이며 현재 프로세스가 실행 중이라는 뜻은 아니다. `최신 설정`을 기다리는 동안 새로 입력한 내용은 늦게 도착한 조회 응답으로 지우지 않는다.

## 패널 표현과 접근성

기존 무광 표면, 얇은 구분선, 상태 색상과 포커스 표현을 재사용한다. 목표 입력과 진행 내용은 패널 안에서 스크롤하며, 저장 버튼은 폼 하단에 둔다. 패널 너비가 440px 이하이면 감독·우선순위 입력을 한 열로 배치하고 저장 영역을 줄바꿈한다. 이는 좁은 캔버스 패널 대응이며 모바일 전용 화면을 의미하지 않는다.

탭에는 연결된 패널과 선택 상태를 제공한다. 좌우 방향키와 Home/End로 탭을 이동하며, 저장 상태와 오류는 상태 안내 영역에 표시한다.

## 검증 명령

프로젝트 루트에서 다음 명령으로 스타일 빌드와 세션 관리 검증을 실행한다.

```sh
npm run ui:build
node scripts/verify-session-management.mjs
```
