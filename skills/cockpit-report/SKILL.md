# 콕핏 보고서

사용자가 콕핏 세션에서 "보고서 써줘", "진행 보고서", "HTML로 보고", "보고서 업데이트"처럼 요청하면 파일 작성과 콕핏 보고서 탭 등록을 함께 처리합니다. 등록 여부를 다시 묻거나 사용자에게 경로와 API 사용법을 전달하도록 요구하지 않습니다. 사용자가 등록을 원하지 않으면 그 지시를 따릅니다.

## 작성과 등록

1. 지정된 경로와 형식을 우선합니다. 지정이 없으면 현재 작업 프로젝트의 `docs/reports/`에 Markdown으로 저장합니다. 기존 보고서 갱신은 같은 파일을 수정합니다. 결과, 검증 근거, 남은 업무를 실제 확인한 범위대로 적습니다.
2. 파일을 저장한 뒤 이 스킬의 `scripts/register.py`를 실행합니다. 전체 경로를 전달하고 제목과 본인 세션 별칭을 선택적으로 지정합니다. 아래 스킬 경로는 현재 읽은 `SKILL.md`의 폴더로 바꿉니다.

   ```bash
   /usr/bin/python3 /스킬/전체/경로/scripts/register.py /보고서/전체/경로.md --title "진행 보고서" --session "ai7"
   ```

3. `ok: true` 응답은 서버에 저장된 목록에서도 동일한 보고서 ID와 경로를 확인했다는 뜻입니다. 확인된 뒤 사용자에게 **보고서 탭에 등록됨**과 원본 경로를 짧게 알립니다.

등록 요청 성공 후 조회가 실패하면 `registered: true, ok: false`로 구분합니다. 파일은 보존하고 등록 확인이 끝나지 않았음을 알립니다. 자동 재실행이나 성공으로 추정하지 않습니다.

## 파일과 접근 범위

- 등록된 프로젝트 폴더 안의 HTML·MD 일반 파일, 2MB 이하만 등록됩니다. 접근 거절을 우회하려고 프로젝트를 추가하거나 민감한 파일을 복사하지 않습니다.
- 기본 주소는 로컬 `http://127.0.0.1:3847`입니다. 기존 `COCKPIT_URL` 또는 `COCKPIT_PORT` 설정을 따르며 등록 요청은 로컬 서버로만 보냅니다.
- HTML은 스크립트와 외부 리소스를 쓰지 않는 단일 파일로 만듭니다. Markdown 표·목록·코드 블록도 미리 볼 수 있습니다.
- 비밀번호·토큰·고객 원문을 보고서에 추가하지 않습니다. 외부 문의 문서는 기존 저장 위치와 공유 규칙을 따르며 자동 등록하지 않습니다.
- 등록 실패가 업무 완료를 뜻하지 않습니다. 확인하지 않은 결과를 완료로 적지 않습니다. 보고서 등록을 위해 다른 작업 세션에 입력하거나 재시작하지 않습니다.
