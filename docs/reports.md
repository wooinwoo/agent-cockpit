# 보고서 관리

콕핏의 **보고서** 탭에서 여러 프로젝트의 HTML·Markdown 파일을 등록하고 읽습니다. 보고서 내용은 복사하지 않고 원본 경로를 연결합니다. 등록 목록은 사용자 데이터 폴더의 `reports.json`에 저장되므로 서버를 다시 시작해도 유지됩니다.

## 사용 방법

1. **보고서 등록**을 누르고 실제 파일의 전체 경로를 입력합니다. Windows 경로도 WSL 경로로 변환합니다.
2. 제목과 작성 세션을 선택적으로 입력하고 **목록에 등록**을 누릅니다.
3. 제목·프로젝트·세션·경로를 검색하거나 HTML·MD 형식으로 좁힙니다.
4. 목록에서 보고서를 선택해 미리 봅니다. **새로고침**하면 수정 시간과 선택한 원본 내용을 다시 읽습니다.
5. **경로 복사**, **파일 내려받기**, **목록에서 삭제**를 사용할 수 있습니다. 삭제는 등록 목록에서만 제거하며 원본 파일은 유지합니다.
6. **목록 접기**를 누르면 보고서 목록과 등록 영역을 숨기고 미리보기를 화면 안에서 넓게 펼칩니다. **목록 보기**로 다시 열 수 있습니다. 선택한 보고서와 검색 조건은 그대로 유지되며, 전체화면으로 전환하지 않습니다. 접힌 상태에서 **보고서 등록**을 누르면 등록 영역이 다시 열립니다.
7. 앱 맨 왼쪽의 콕핏 메뉴는 상단 맨 왼쪽 **메뉴 접기** 버튼으로 숨깁니다. 같은 자리의 **메뉴 펼치기**로 복원합니다. 접힌 상태는 새로고침 후에도 유지되며 모바일 하단 메뉴에는 적용하지 않습니다. 보고서 목록과 앱 메뉴를 각각 접을 수 있습니다.

터미널 출력의 HTML·MD 파일 경로를 우클릭하고 **보고서로 등록**을 선택해도 등록 화면이 열립니다. 같은 경로는 하나의 항목으로 유지합니다. 제목이나 세션을 입력해 다시 등록하면 해당 정보를 갱신하고, 비워두면 기존 정보를 유지합니다.

파일이 사라지면 목록에서 경로 확인이 필요하다고 표시합니다. 원본을 복원한 뒤 새로고침하거나 해당 항목을 목록에서 제거할 수 있습니다. 등록·조회 실패는 화면에 표시하며 등록 입력과 마지막 정상 목록은 보존합니다.

## 파일과 접근 범위

- 등록된 프로젝트 폴더 안의 `.html`, `.htm`, `.md`, `.markdown` 일반 파일을 지원합니다.
- 미리보기 파일 크기는 2MB 이하이며 등록 목록은 최대 500개입니다.
- HTML 미리보기는 격리된 프레임에서 스크립트와 외부 리소스를 차단합니다. 인라인 스타일과 데이터 이미지가 포함된 정적인 단일 HTML 파일에 적합합니다. 동적인 HTML은 내려받은 파일로 확인합니다.
- Markdown의 제목·목록·표·코드 블록을 표시합니다. 원문 HTML은 텍스트로 표시합니다.
- 현재 기능은 Rust 서버에 구현했습니다. 인증된 원격 접속에서 조회할 수 있으며 등록과 목록 제거는 로컬에서 합니다.
- 제목과 작성 세션은 등록자가 입력하는 분류 정보입니다. 보고서의 업무 완료를 자동 판정하는 근거로 사용하지 않습니다.

## AI와 도구에서 등록

보고서 기본 안내가 설치된 콕핏 세션에서는 **“보고서 써줘”** 또는 **“보고서 업데이트해”**라고 요청하면 파일 작성과 보고서 탭 등록을 함께 처리합니다. 형식과 경로를 지정하지 않으면 작업 프로젝트의 `docs/reports/`에 Markdown으로 저장합니다. 기존 보고서를 갱신하면 같은 원본 경로를 사용합니다. 등록 후 목록에서도 같은 ID와 경로를 확인하며, 저장 성공 뒤 조회 실패는 구분해서 알립니다. 외부 문의 문서는 기존 저장·공유 규칙을 따릅니다.

기본 안내는 `skills/cockpit-report/SKILL.md`와 등록 도우미 `skills/cockpit-report/scripts/register.py`에 있습니다. 사용자 전역 안내와 jcode의 추가 프롬프트가 이 스킬을 연결합니다. 안내는 모델의 작업 지침이며 작성·등록을 서버가 강제로 실행하는 기능은 아닙니다.

로컬 HTTP API를 사용할 수 있습니다. 아래 `path`는 실제 존재하는 보고서 경로로 바꿉니다.

```http
POST /api/reports
Content-Type: application/json

{"path":"/절대/경로/보고서.md","title":"진행 보고","session":"ai7"}
```

`GET /api/reports`는 파일 수정 시간·프로젝트·가용 상태를 포함한 목록을 반환합니다. `DELETE /api/reports/{id}`는 등록 항목만 제거합니다. 원본 파일 내용은 기존 `GET /api/file?path=...` API의 프로젝트 접근 검사를 통해 읽습니다.

## 검증

`scripts/verify-reports.mjs`는 격리된 Rust 서버에서 등록·중복·원격 접근·재시작 보존·HTML 격리·다운로드·지연 응답·입력 보존·삭제·네 화면 크기를 검사합니다. 실제 작업 세션에는 메시지나 키 입력을 보내지 않습니다.
