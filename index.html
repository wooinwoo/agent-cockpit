      Terminal & Canvas Keys

      Alt controls sessions, canvas, and scrollback. Hold K or L for continuous scrolling.

      Sessions & groups

      Alt 1–9Jump to a numbered session
      Alt Q / WPrevious / next session
      Ctrl TabNext session; add Shift for previous
      Alt GStart or cancel grouping, then press Alt + 1–9
      Alt Shift GCycle the active group layout

      Terminal scrollback

      Alt K / LScroll up / down 3 lines; hold to continue
      Alt Shift K / LScroll up / down one page
      Alt EndJump to the latest terminal output
      Ctrl FSearch terminal output

      Canvas

      Alt ArrowMove the selected frame
      Alt Shift ArrowResize the selected frame
      Ctrl WheelZoom at the pointer
      Shift WheelPan horizontally
      DragPan from blank canvas background
      EnterFocus a keyboard-selected terminal frame

      Terminal actions

      Ctrl TNew terminal
      Ctrl WClose active terminal
      Ctrl JToggle quick command bar
      Ctrl BToggle broadcast mode
      Ctrl Shift \Split right
      Ctrl Shift −Split below
